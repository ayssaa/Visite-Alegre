# Visite Alegre

Projeto Visite Alegre: um site para o administrador de uma aplicação web sobre a cidade de Alegre — com páginas para cadastro de pontos turísticos, roteiros, eventos e guias.

Arquivos principais:
- `inicio.html` — página inicial
- `pontos.html` — pontos turísticos
- `roteiro.html` — roteiros sugeridos
- `eventos.html` — agenda de eventos
- `guias.html` — informações sobre guias
- `login.html` — página de login
- `style.css` e a pasta `img/`

Integrantes:
- ANDRÉ DESTEFANI STEFANATO
- AYSSA HADASSA DE PAIVA AMORIM
- GUILHERME ANDRADE NASCIMENTO MEDEIROS
