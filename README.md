# Visite Alegre — Sistema de Gerenciamento Turístico

Este repositório contém o projeto **Visite Alegre**, desenvolvido como trabalho acadêmico da disciplina de **Banco de Dados**, da Universidade Federal do Espírito Santo (UFES) — Campus Alegre.

## Sobre o Projeto

O **Visite Alegre** é um sistema de informação voltado ao gerenciamento e à organização de dados turísticos do município de Alegre, no Espírito Santo.

## Funcionalidades

O sistema foi projetado para contemplar:

- Cadastro e gerenciamento de pontos turísticos;
- Cadastro e gerenciamento de eventos;
- Cadastro de turistas, guias e administradores;
- Autenticação de usuários;
- Criação e gerenciamento de roteiros turísticos;
- Inscrição de turistas em roteiros;
- Registro de avaliações de pontos turísticos;
- Operações CRUD (Create, Read, Update e Delete).

## Banco de Dados

O projeto utiliza **MySQL** como sistema gerenciador de banco de dados relacional.

Durante o desenvolvimento acadêmico, foram abordados conceitos fundamentais de Banco de Dados, incluindo:

- Levantamento de requisitos funcionais e não funcionais;
- Modelagem conceitual e relacional;
- Diagrama Entidade-Relacionamento (DER);
- Definição de entidades, atributos e relacionamentos;
- Chaves primárias e estrangeiras;
- Integridade referencial;
- Dicionário de dados;
- Matriz de rastreabilidade;
- Diagramas e descrições de casos de uso.
