# Visite Alegre

Projeto Visite Alegre: um site para o administrador de uma aplicação web sobre a cidade de Alegre — com páginas para cadastro de pontos turísticos, roteiros, eventos e guias.

Arquivos principais:
- `inicio.php` — página inicial
- `pontos.php` — pontos turísticos
- `roteiro.php` — roteiros sugeridos
- `eventos.php` — agenda de eventos
- `guias.php` — informações sobre guias
- `login.php` — página de login
- `style.css`, `img/` e `script.js`
